# Solana dApp Project

A full-stack Solana dApp with separate frontend and backend directories.

## Project Structure

```
noshot/
├── frontend/          # Next.js frontend application
│   ├── app/          # Next.js App Router
│   ├── components/   # React components
│   ├── lib/          # Utility functions
│   ├── styles/       # Tailwind CSS
│   └── public/       # Static assets
├── backend/          # Backend API (empty - to be implemented)
└── README.md         # This file
```

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
The backend directory is currently empty and ready for implementation.

## Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: TBD
